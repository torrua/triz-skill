> **Главная аксиома:** Ищи изобретательское решение в первую очередь; если непреодолимый физический предел сохраняется, открыто зафиксируй доказательства и последствия, вместо того чтобы выдумывать ложные гарантии.

## Что это такое?

Навык для ИИ-агентов, применяющий **ТРИЗ (Теорию Решения Изобретательских Задач)**, созданную Генрихом Сауловичем Альтшуллером. Вместо того чтобы предлагать «сбалансированные компромиссы» и половинчатые меры, навык направляет агента по строгому 5-шаговому конвейеру **АРИЗ-AI (ARIZ-AI)** для поиска решений, полностью устраняющих противоречия с использованием только имеющихся ресурсов системы, классифицирует ограничения и отделяет доказанные факты от гипотез.

## Архитектура

```
triz-universal/
├── SKILL.md                           ← Уровень 1: Компактный диспетчер (~180 строк)
└── references/                        ← Уровень 2: Углубленные модули (по требованию)
    ├── README.md                      Навигационный указатель
    ├── 01-ikr-ideality.md             Идеальный Конечный Результат (ИКР) и формула идеальности
    ├── 02-contradictions.md           Переход: Административное → Техническое → Физическое противоречие
    ├── 03-separation-principles.md    7 стратегий разрешения (Литвин + Злотин/Зусман)
    ├── 04-ariz-lite-algorithm.md      Пошаговый протокол АРИЗ-AI с разбором кейсов
    ├── 05-40-principles-catalog.md    Каталог 40 приемов с каноническими русскими названиями
    ├── 06-system-operator-9screens.md Системный оператор (9 экранов) и анти-система
    ├── 07-resource-audit-vpr.md       Каталог аудита ресурсов (ВПР)
    ├── 08-multi-domain-lenses.md      Междоменная адаптация + модель ЭИЗ (OTSM-ТРИЗ)
    ├── 09-su-field-and-standards.md   Вепольный анализ и 76 стандартов Альтшуллера
    ├── 10-testing-scenarios.md        5 бенчмарков стресс-тестирования (RED vs GREEN)
    ├── 11-contradiction-matrix.md     Кураторская матрица 39 параметров
    ├── 12-evaluation-suite.md         5 эталонных задач с критериями оценки
    ├── 13-perception-mapping.md       Бизнес-ТРИЗ: картирование восприятия для организаций
    ├── SOURCES.md                     Политика провенанса и классификация источников
    └── CLAIMS.md                      Реестр утверждений и уровни уверенности
```

**Почему двухуровневая архитектура (Tier-2)?** Загрузка всей теории ТРИЗ в контекст сразу тратит токены и вызывает эффект «потери в середине» (*lost-in-the-middle*). Диспетчер `SKILL.md` компактен и находится в памяти всегда, а детальные справочники подгружаются моделью через tool calls **только при необходимости**.

## Установка

### Для Google Antigravity (Gemini CLI / IDE)

Скопируйте навык в глобальный каталог навыков:

```bash
# Linux / macOS
cp -r triz-universal/ ~/.gemini/config/skills/triz-universal/

# Windows (PowerShell)
Copy-Item -Recurse triz-universal\ "$env:USERPROFILE\.gemini\config\skills\triz-universal\"
```

Или используйте скрипт синхронизации:

```powershell
.\scripts\sync-deployment.ps1 -Mode Apply -Destination "$env:USERPROFILE\.gemini\config\skills\triz-universal"
```

### Для других ИИ-агентов (Claude Desktop, Cursor, OpenAI Agents)

Навык представляет собой набор Markdown-файлов. Скопируйте папку `triz-universal/` в каталог навыков вашего агента и настройте триггеры на ключевые слова: `ТРИЗ`, `TRIZ`, `противоречие`, `компромисс`, `trade-off`, `bottleneck`, `ИКР`, `архитектурный тупик`.

## Как это работает

Когда вы задаете агенту задачу вида:

> *«Нашему API нужна задержка чтения менее 10 мс И строгая согласованность ACID для аналитических записей»*

Вместо шаблонного ответа *«Давайте найдем разумный компромисс и пожертвуем частью данных...»*, навык ТРИЗ заставляет агента выполнить шаги:

1. **Классифицировать ограничения** — отделить жесткие инварианты (ACID) от ориентиров и предположений.
2. **Сформулировать ИКР** — использовать идеальный результат как вектор поиска («Система сама обеспечивает мгновенное чтение без дополнительных серверов»).
3. **Обострить Физическое Противоречие (ФП)** — «Путь доступа к данным должен быть свободен от блокировок (для чтения <10мс) И обязан содержать блокировку (для обеспечения инварианта транзакции)».
4. **Провести аудит ресурсов (ВПР)** — проверить page cache ОС, sequential WAL-логи, свободные ядра CPU, структуру разделения данных.
5. **Применить операторы разделения** — например, разделение во времени (MVCC / снапшоты) или в структуре (CQRS / Striped locks).
6. **Верифицировать результат** — сформировать план проверки, указать уровень доказанности и открыто перечислить остаточные риски.

### Локализованный шаблон вывода

Агент формирует решение по стандартизированному шаблону:

```markdown
### 💡 ТРИЗ-Изобретательское Решение
- **Физическое противоречие (ФП):** [Элемент X должен обладать свойством P для R1, и НЕ-P для R2]
- **Диагностический путь:** [ГДЕ / КОГДА / ПО СОСТОЯНИЮ / СТРУКТУРА / СОВМЕЩЕНИЕ / ОБХОД / АЛЬТ-СИСТЕМА]
- **Примененная стратегия:** [В пространстве | Во времени | По состоянию | По структуре | Совмещение | Обход | Альтернативная система]
- **Использованный прием(ы):** [Прием №N: Каноническое русское название — и ПОЧЕМУ выбран]
- **Мобилизованный ресурс (ВПР):** [Использованный бесплатный внутренний/надсистемный ресурс]
- **Решение:** [Суть механизма устранения противоречия без компромисса]
- **Доказательная база и уверенность:** [Факт | Паттерн | Гипотеза; источник или обоснование]
- **План верификации:** [Базовая линия, эксперимент, порог успеха и ответственный]
- **Остаточные риски:** [Неустранимые пределы, приватность, комплаенс, стоимость и сбои]
- **Проверенный результат:** [Измеренный результат или ожидаемый эффект]
```

## Тестирование

Запуск полного набора автоматизированных тестов:

```bash
python -m unittest discover tests
```

Тестовый набор покрывает:
- Валидацию метаданных YAML и соответствие стандартам разработки навыков
- Целостность ссылок между всеми 15 модулями
- Барьеры против рационализации компромиссов (Anti-Rationalization Guardrails)
- Формулировку 5-шагового конвейера АРИЗ-AI
- Оценку бенчмарков стресс-тестирования (RED-базовые отказы vs GREEN-решения)
- Классификацию ограничений, уровни доказательств и отчетность по рискам
- Реестры источников и утверждений (`SOURCES.md`, `CLAIMS.md`)
- Русскоязычные триггеры, русскоязычный шаблон вывода и 40 канонических названий приемов Альтшуллера

Для проверки или синхронизации установленной копии навыка:

```powershell
.\scripts\sync-deployment.ps1 -Mode Check -Destination "$env:USERPROFILE\.gemini\config\skills\triz-universal"
.\scripts\sync-deployment.ps1 -Mode Apply -Destination "$env:USERPROFILE\.gemini\config\skills\triz-universal"
```
